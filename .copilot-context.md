# Contexto del Proyecto - GenericAutonomousRobot (GAR)

## Descripción General

**GenericAutonomousRobot** es una plataforma educativa de robótica autónoma diseñada para estudiantes de Ingeniería Electrónica. El proyecto integra sistemas de tiempo real, procesamiento digital de señales (DSP) y conectividad IoT en un rover autónomo.

**Objetivo Principal**: Crear una plataforma modular que combine hardware embebido con análisis técnico y capacidades de navegación autónoma.

---

## Arquitectura del Sistema

### Hardware
- **MCU de Control**: STM32F407VG (ARM Cortex-M4 a 168MHz)
  - Ejecuta FreeRTOS
  - Controla motores, sensores y lógica de navegación
  - Implementa filtros DSP (FIR/IIR)

- **MCU de Comunicaciones**: ESP32-S3 DevKit (Dual-Core Xtensa)
  - Gateway IoT y telemetría
  - Conectividad WiFi/Bluetooth
  - Monitoreo en tiempo real

- **Sensores**:
  - MPU6050: Unidad de Medición Inercial (IMU)
  - HC-SR04: Sensor Ultrasónico (detección de obstáculos)
  - 5x TCRT5000: Sensores Infrarrojos (detección de acantilados)

- **Actuadores**:
  - 2x Motores DC controlados por TB6612FNG

## Estructura del Proyecto

### `/Firmware`
Código embebido para ambos microcontroladores.

#### `/Firmware/stm32_control`
- **Tecnología**: ARM Embedded-C + FreeRTOS
- **Estructura**:
  - `Core/Src/main.c`: Punto de entrada principal
  - `Core/Src/drv_motor.c`: Driver para motores DC
  - `Core/Src/drv_ultrasound.c`: Driver para sensor ultrasónico
  - `Core/Src/mid_kinematics.c`: Cálculos de cinemática del rover
  - `Core/Src/i2c.c`, `spi.c`: Interfaces de comunicación
  - `Core/Src/stm32f4xx_hal_*.c`: Driver del hardware abstraction layer
- **Build**: Basado en Makefile ARM Cross-Compiler
- **Roles principales**:
  - Control de tasks en tiempo real
  - Adquisición de sensores (IMU, ultrasónico, infrarrojo)
  - Control de actuadores (motores)
  - "Black Box" logging para análisis post-mortem

#### `/Firmware/esp32_gateway`
- **Tecnología**: C + ESP-IDF + PlatformIO
- **Estructura**:
  - `src/main.c`: Punto de entrada
  - Comunicación UART con STM32
  - Interfaz WiFi para telemetría
  - Gestión de energía y conectividad
- **Build**: PlatformIO + CMake
- **Roles principales**:
  - Puente de comunicación
  - Monitoreo remoto
  - Logging en la nube (TBD)

## Conceptos Clave del Proyecto

### 1. **Sistemas de Tiempo Real (RTOS)**
- FreeRTOS ejecutándose en STM32F4
- Tasks con prioridades preemptivas
- Comunicación inter-tareas mediante colas y semáforos
- Gestión de recursos críticos en tiempo real

### 2. **Procesamiento Digital de Señales (DSP)**
- Filtros FIR e/o IIR para acondicionamiento de sensores
- Análisis de estabilidad y respuesta en frecuencia
- Implementación eficiente en C para ARM

### 3. **Navegación Autónoma**
- Evitación de obstáculos mediante ultrasónico (HC-SR04)
- Detección de acantilados mediante sensores IR (TCRT5000)
- Control de motores mediante PWM
- Integración IMU para orientación (MPU6050)

### 4. **Black Box & Pericias Técnicas**
- Logging automático de eventos en flash
- Post-mortem análisis de fallos
- Generación de reportes técnicos detallados
- Cumplimiento de estándares de análisis forense

### 5. **IoT & Conectividad**
- ESP32 como gateway de comunicación
- Telemetría en tiempo real
- Integración potencial con cloud
- OTA (Over-The-Air) updates

## Patrones de Código Importantes

### En STM32:
- **RTOS Tasks**: Funciones void (*)(void*) registradas en FreeRTOS
- **Drivers**: Abstracción HAL para periféricos
- **Middleware**: Filtros DSP, kinematics, control
- **Logging**: Sistema de black box en flash

### En ESP32:
- **Tasks**: Similares a FreeRTOS
- **Event Loops**: Para eventos WiFi y UART
- **JSON**: Para serialización de telemetría

---

## Puntos de Integración Clave

1. **UART STM32 ↔ ESP32**: Protocolo binario de comunicación
2. **I2C (STM32)**: Conexión con MPU6050
3. **GPIO/PWM (STM32)**: Control de motores y lecturas de sensores digitales
4. **SPI (STM32)**: Potencial lectura de flash para black box
5. **WiFi (ESP32)**: Gateway para telemetría remota

# Contexto de GenericAutonomousRobot

Proyecto del Grupo 1 para TDIII y MEII. Consultar el [README](README.md) para el estado y los procedimientos, y la [arquitectura](Docs/ARCHITECTURE.md) para las tareas, el hardware y las interfaces vigentes. Usar el código y la configuración activos para verificar valores concretos. Los procedimientos y resultados por etapa están en [Docs/Pruebas](Docs/Pruebas). Los runners y mocks siguen en `Tests/` dentro de cada proyecto de firmware.

- `Firmware/stm32_control` contiene el firmware de adquisición, Safety, navegación y movimiento.
- `Firmware/esp32_gateway` contiene el enlace UART, la API HTTP y el panel local.
- Verificar impacto en Safety, STOP, autorizaciones de movimiento y vigencia de datos al cambiar módulos de control o comunicación.
- Seguir la [guía de estilo](Docs/CODING_STYLE.md): identificadores en inglés, comentarios técnicos en español, variables en `snake_case`, funciones con formato `Modulo_Accion()`, tipos en `PascalCase` con sufijo `_t` y constantes en mayúsculas.
